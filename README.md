# 北茨城市タイピング探検

北茨城市の言葉（地名・学校・名所・自然・あんこう・おまつりなど）をローマ字で打ちながら、「ふるさとカード」を集めるタイピングゲームです。画面の中で終わらず、実際の町へ出かけたくなることをねらっています。

- 遊ぶ：https://heino-naka.github.io/kitaibaraki-typing/
- 対象：北茨城市のこども（学校の Chromebook・パソコンのキーボードで遊びます）
- 登録・ログイン：不要。得点・あんこう・カードは、使っているパソコンのブラウザの中だけに保存され、外部には送信されません。
- 「いばらきタイピング探検MAP」：https://heino-naka.github.io/ibaraki-typing-map/

## 内容
- 本編は60秒（かんたん／ふつう／むずかしい）。速さよりも正確さを大切にした得点です。
- 「れんしゅう」では、時間を気にせず10・20・30語を練習できます（得点・あんこう・カードは変わりません）。
- ふるさとカードは159枚（北茨城の40の町を含む）。ガチャで集めます。
- 学校・園・施設などの名前は、公式の名称を使っています。評価や比較を目的にした表示はしていません。

## 利用について
学校・自治体・ご家庭では、自由にお使いください。

このゲームは、紹介してもらうことが何よりの励みです。リンクを送ったり、SNSやLINEで紹介したり、スクリーンショットを投稿したりすることは、大歓迎です。

ゲームのファイルを、作り変えて配ったり、売ったりすることは、ご遠慮ください。作者名の表示は、そのままにしてください。
